## 최고의 인재를 채용하고 육성한다 (Hire and Develop the Best):

> "최고의 인재를 채용하고 그들의 성장에 기여합니다."

### **아마존의 공식 설명:**

> 리더는 채용과 승진 과정에서 **성과 기준을 지속적으로 높인다.**
>
> 뛰어난 인재를 알아보고, 그들이 조직 전반에 걸쳐 **최적의 위치로 이동할 수 있도록 돕는다.**
>
> 리더는 **리더를 길러내는 사람**이며, **코칭과 멘토링** 역할을 중요하게 여긴다.

### **이 원칙의 실제 의미는?**

이 원칙은 단순히 “사람을 잘 뽑는 것”을 넘어서,

**“잠재력 있는 인재를 알아보고, 그들이 성장할 수 있도록 적극적으로 지원하는 것”**을 뜻합니다.

- **성과 중심의 채용**
- **잠재력 기반의 육성**
- **리더로 성장시킬 수 있는 코칭과 피드백 제공**
- **조직 전체를 생각한 인재 이동 및 배치**

### **IC(개별 기여자)도 이 원칙을 준비해야 할까?**

이 원칙은 기본적으로 **사람을 관리하는 역할(Manager, Lead)**에 해당하는 원칙입니다.

따라서 IC(Individual Contributor) 지원자라면 대부분은 크게 신경 쓰지 않아도 됩니다.

다만 아래 유형의 질문은 IC에게도 나올 수 있습니다:

- **후배 직원에게 피드백 또는 코칭한 경험**
- **직속 팀원이 아니지만, 누군가의 성장을 도왔던 사례**

### **관련 리더십 원칙**

사람을 관리하는 직책이라면 다음 두 가지 원칙 모두 중요합니다:

- **#6: Hire and Develop the Best**
- **#15: Strive to be Earth’s Best Employer (지구 최고의 고용주가 되자)**

### **자주 나오는 면접 질문 예시**

| **질문 유형** | **예시** |
| --- | --- |
| 채용 경험 | 당신의 채용 방식은 무엇인가요?가장 성공적인 채용 사례를 들려주세요. |
| 인재 육성 | 팀원의 성장을 돕기 위해 어떤 노력을 하나요?문제가 있었던 직원에게 투자한 경험이 있나요? |
| 피드백 및 코칭 | 팀원의 강점을 살리기 위한 피드백을 준 경험은?가장 효과적이었던 코칭 방법은? |
| 상위 성과자 관리 | 상위 성과자를 어떻게 다르게 관리하나요? |
| 승진 사례 | 당신의 코칭 덕분에 1~2단계 승진한 팀원이 있었나요? |
| 팀 구성 | 당신의 팀 구성은 어떤가요?조직 구조는 어떻게 되어 있나요? |
| 다양성 & 포용 | 당신의 팀은 다양한가요?다양한 팀을 구성하기 위해 어떤 노력을 했나요? |

### **이 원칙을 준비할 때 갖춰야 할 스토리 유형**

**2개 정도면 충분하다는 말은 이 원칙엔 적용되지 않습니다.**

관리직 지원자라면, 다음 각 항목에 대해 최소 1개 이상의 경험을 준비하세요:

| **영역** | **준비 사례** |
| --- | --- |
| 채용 | 뛰어난 인재를 채용한 경험 |
| 인재 육성 | 평균 이하 팀원을 성장시킨 경험 |
| 상위 성과자 관리 | 탑 퍼포머를 유지/승진시키기 위한 맞춤형 전략 |
| 코칭 및 피드백 | 주기적인 피드백으로 성장 지원한 사례 |
| 다양성 확보 | 편향 없이 다양한 배경의 인재 채용에 성공한 경험 |
| 팀 빌딩 및 재구성 | 팀 전체를 성장시킨 구조 개편 사례 등 |

### **좋은 답변에 포함되어야 할 4가지 요소**

1. **채용 역량**
   - 직무에 적합한 인재를 정의하고, 인터뷰를 구조화하며, 성과 기준에 맞춰 평가
2. **성과자 중심의 관리**
   - 성과가 높은 인재에게 더 많은 리소스를 투자하며 리더로 성장시키는 문화
3. **성장과 코칭을 중시하는 문화**
   - 정기적인 1:1 미팅, 커리어 플래닝, 성장 기회 부여
4. **다양성을 수용하는 사고방식**
   - 나와 다른 배경을 가진 사람을 고용하고, 다양한 관점을 환영하는 팀 구성

### **피해야 할 응답 예시**

- “나는 모든 직원을 평등하게 코칭한다.” → Amazon은 **상위 성과자 중심** 문화입니다.
- “성과 낮은 직원을 중심으로 개선 활동을 한다.” → 이는 보완은 되나, Amazon에서는 **성과자 성장**이 우선입니다.
- “다양성에 특별히 신경 써본 적은 없다.” → Tech 업계의 현실상, **의식적인 다양성 노력**은 강점으로 작용합니다.

### **정리**

| **키워드** | **내용** |
| --- | --- |
| **채용** | 최고의 인재를 채용하고, 성과 기준을 높인다. |
| **코칭** | 팀원의 성장 가능성을 확인하고, 적극적으로 피드백/육성한다. |
| **성과자 관리** | 잘하는 사람에게 더 많은 기회를 준다. |
| **팀 다각화** | 다양한 사람들을 모아 고객 관점과 문제 해결력을 강화한다. |
