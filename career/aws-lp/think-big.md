## 크게 생각한다 (Think Big):

> "큰 목표를 설정하고 혁신적인 접근법을 추구합니다."

### **아마존의 공식 설명:**

> 작게 생각하면, 그 생각이 곧 현실이 된다.
>
> 리더는 **대담한 방향을 설정하고 이를 명확히 전달함으로써** 사람들을 고무시키고 결과를 이끌어낸다.
>
> 리더는 **새로운 시각**으로 사고하고, 고객을 위한 기회를 **미리 내다본다.**

### **“Think Big” 원칙의 의미는?**

“Think Big(크게 생각한다)”는 말은 곧 **야망을 갖고 한계를 두지 않으며**,

**혁신적인 방향 설정과 대담한 실행을 주도한다**는 뜻입니다.

### **“Think Big” 하는 사람의 특징:**

- 문제를 **도전과 기회**로 바라본다
- **긍정적 사고**를 바탕으로 해결책을 찾는다
- 할 수 없는 이유가 아닌 **할 수 있는 방법**을 탐색한다
- 불가능에 집중하지 않고, **가능한 것을 구상**한다
- **두려움 없이 시도**한다
- 창의적으로 생각하며, **비전을 시각화**할 수 있다

### **실제 아마존의 기대**

- **기존 방식을 의심하고**, 근본적으로 다른 해결책을 제안한다
- 팀이 **열광할 수 있는 대담한 미션**을 설정하고, 이를 구체적인 행동 계획으로 연결한다
- **장기적인 전략과 비전**을 지속적으로 공유하며 팀의 방향성을 정렬시킨다
- 팀원들의 **자발적인 아이디어와 리스크 감수**를 장려한다

### **“Think Big” 관련 면접 질문 예시**

| **질문 유형** | **질문 내용** |
| --- | --- |
| **계산된 리스크** | 목표 달성을 위해 **계산된 리스크**를 감수한 경험은? 결과와 트레이드오프는 무엇이었나요? |
| **실패한 도전** | 큰 도전을 시도했으나 실패한 경험이 있나요? 무엇을 배웠고, 다음엔 어떻게 다르게 하겠습니까? |
| **스코프 초과 달성** | 프로젝트 범위를 넘어 훨씬 큰 결과를 만들어낸 경험은? |
| **가장 자랑스러운 성과** | 당신이 가장 자랑스럽게 생각하는 직무 성취는 무엇인가요? |
| **급진적 접근법** | 문제 해결을 위해 **전혀 새로운 접근 방식**을 제안했던 사례가 있나요? 성공했나요? |
| **비전 전파와 채택** | 당신의 아이디어/비전을 조직에 전파한 경험은? 어떻게 확산되었고, 결과는 어땠나요? |
| **스케일 확대** | 원래 계획보다 훨씬 큰 기회를 발견하고 **스케일을 키운 경험**이 있나요? |
| **기존 프로세스 재검토** | 잘 작동하고 있던 프로세스를 재검토하고, 더 나은 방법을 찾으려 했던 경험은? 어떤 가정들을 의심했나요? |

### **몇 개의 사례를 준비해야 할까?**

일반적으로 리더십 원칙당 **2개의 사례**가 권장되지만,

“Think Big”은 다양한 방향의 질문이 나올 수 있으므로, **2개로는 부족할 수 있습니다.**

▶ **전략**:

- **4개 이상의 유연한 사례 풀**을 준비하고,
- “Invent and Simplify”, “Bias for Action”, “Ownership” 등과 겹칠 수 있는 이야기로 **다중 응답 가능**하게 구성하세요.

### **피해야 할 응답 유형**

- “기존 방식이 충분하다고 생각해서 그대로 유지했다” → **보수적 사고**로 보임
- “리스크를 감수할 여유가 없었다” → **실험과 혁신**에 소극적인 태도로 해석
- “작은 개선만 반복적으로 시도했다” → “Think Small”로 간주될 수 있음

### **정리**

| **핵심 질문** | **확인하려는 역량** |
| --- | --- |
| 얼마나 **대담하게 기획**할 수 있는가? | 창의성, 전략적 사고 |
| **기존을 의심하고 새로운 접근을 시도**했는가? | 도전정신, 혁신성 |
| **비전을 공유하고 팀을 설득**한 경험이 있는가? | 리더십, 커뮤니케이션 |
| 실패로부터 **무엇을 배웠는가?** | 회복탄력성과 성장지향 마인드 |
