## STAR 기법이란?

**STAR 기법**은 행동 면접(Behavioral Interview) 질문에 구조적으로 답하기 위한 프레임워크로,

지원자가 **과거의 실제 경험을 기반으로 문제 해결 능력**을 효과적으로 보여줄 수 있도록 돕습니다.

> STAR은 다음 네 단계의 약자입니다:

> **S = Situation (상황)**
>
> **T = Task (과제)**
>
> **A = Action (행동)**
>
> **R = Result (결과)**

### 각 단계 설명

#### S: Situation (상황)

- 사건이 발생한 배경은 무엇인가?
- 언제, 어디서, 누구와 관련된 일이었는가?
- 맥락이 이해될 수 있도록 간결히 설명

예시:

“2023년, 우리 팀은 고객사의 요청으로 대규모 시스템 마이그레이션 프로젝트를 진행하게 되었습니다.”

#### T: Task (과제)

- 당신이 맡은 구체적인 목표는 무엇이었나?
- 어떤 책임과 도전 과제를 안고 있었는가?

예시:

“저는 프로젝트 리더로서 일정 내 시스템 전환을 마치고, 데이터 손실 없이 마이그레이션을 완수해야 했습니다.”

#### A: Action (행동)

- 문제 해결을 위해 어떤 행동을 취했는가?
- 어떤 전략과 의사결정을 내렸는가?
- 다른 사람들과 어떤 협업이 있었는가?

예시:

“업무를 세 개의 단계로 나눠 진행하고, 리스크를 줄이기 위해 주간 점검 회의를 운영했으며, 고객과의 실시간 피드백 루프를 만들었습니다.”

#### R: Result (결과)

- 결과적으로 무엇이 달성되었는가?
- 성공 여부는 어떻게 측정했는가?
- 수치나 피드백이 있는가?

예시:

“그 결과 프로젝트는 2주 앞당겨 성공적으로 종료되었고, 고객사로부터 96%의 만족도 평가를 받았습니다.”

## PAR 기법이란?

**PAR 기법**은 행동 면접(Behavioral Interview) 질문에 체계적으로 답변하기 위한 구조로,

다양한 상황을 간결하고 논리적으로 설명할 수 있도록 돕는 **면접 답변 프레임워크**입니다.

> PAR은 다음 세 단어의 약자입니다:

> **P = Problem (문제, 상황)**
>
> **A = Action (행동)**
>
> **R = Result (결과)**

### 각 단계 설명

#### P: Problem (문제/상황)

- 어떤 배경과 맥락에서 문제가 발생했는가?
- 누구와 어떤 상황이었는가?
- 어떤 도전, 갈등, 요구사항이 있었는가?

예시:

“우리 팀은 중요한 클라이언트의 요구 사항 변경으로 마감 일정을 맞추기 어려운 상황에 놓였습니다.”

#### A: Action (행동)

- 그 상황에서 본인이 주도적으로 어떤 행동을 취했는가?
- 어떤 전략, 판단, 조율, 기술적 접근이 있었는가?
- 혼자 했는가, 팀을 리드했는가?

예시:

“저는 우선순위를 재조정하고, 스프린트 계획을 수정했으며, 클라이언트와 직접 커뮤니케이션을 통해 기대치를 조율했습니다.”

#### R: Result (결과)

- 결과는 어땠는가?
- 성공 또는 실패의 원인은 무엇인가?
- 수치화 가능한 성과(성과 지표, 고객 반응 등)는 있는가?
- 팀/조직/고객에게 어떤 영향을 주었는가?

예시:

“그 결과 프로젝트는 예정일보다 하루 앞서 마무리되었고, 고객 만족도 점수는 15% 상승했습니다.”

### PAR vs STAR 비교

| **항목** | **PAR** | **STAR** |
| --- | --- | --- |
| 구조 | 3단계 (문제-행동-결과) | 4단계 (상황-과제-행동-결과) |
| 특징 | **간결하고 명확함** | 상세하지만 중복 가능성 있음 |
| 장점 | 중복 줄이고 스토리에 집중 | 세부 상황 설명에 유리 |
| 추천 대상 | 실무자, 경력직, 리더직 | 신입, 세부 설명이 필요한 경우 |
