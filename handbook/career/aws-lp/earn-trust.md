## 다른 사람의 신뢰를 얻는다 (Earn Trust):

> "정직하고 존중하는 태도로 신뢰를 구축합니다."

### **아마존의 공식 정의:**

> 리더는 **주의 깊게 경청하고, 솔직하게 말하며, 다른 사람을 존중하는 태도**를 갖는다.
>
> **불편하거나 부끄러운 상황에서도 자기 비판적 태도**를 드러낸다.
>
> 그리고 **자신과 팀의 성과를 최고 기준과 비교**하여 향상시킨다.

### **“Earn Trust” 원칙의 실제 의미는?**

#### **이 원칙이 말하는 신뢰는 단순한 “호감”이 아닙니다.**

Amazon에서는 동료 및 팀원과의 신뢰를 다음과 같은 행동을 통해 얻어야 한다고 봅니다:

- **경청**: 상대방의 말을 끝까지 듣고 이해하려는 태도
- **솔직한 커뮤니케이션**: 피드백을 줄 때나 받을 때 **진실되게 표현**
- **존중**: 다양한 의견과 사람에 대한 **기본적 예의와 배려**
- **자기비판**: 자신의 잘못이나 한계에 대해 **공개적으로 인정**하고 개선하려는 태도
- **모범 행동**: 약속을 지키고, 윤리적인 기준을 유지하며, **말보다 행동으로 보여줌**

#### **신뢰는** 실수 안 하기 가 아니라,

**실수를 어떻게 인정하고 처리하느냐**로부터 생깁니다.

### **♂ Amazon에서 “신뢰를 얻는다”는 것은 무엇을 의미할까?**

| **기대 행동** | **설명** |
| --- | --- |
| **협업 기반의 리더십** | 팀원들과 상호 신뢰를 바탕으로 협력함 |
| **자기 인식(Self-awareness)** | 잘못을 감추지 않고 **책임을 지는 리더십** |
| **정직한 피드백 문화** | 칭찬뿐 아니라 **솔직한 비판도 받아들이고 전달할 수 있음** |
| **기준 준수 및 향상** | 스스로와 팀을 업계 최고의 기준과 비교하고 발전시킴 |

### **“Earn Trust” 관련 면접 질문 예시**

| **질문 유형** | **예시 질문** |
| --- | --- |
| **신속한 신뢰 형성** | 빠르게 신뢰를 얻어야 했던 경험은? 어떻게 했나요? |
| **팀 내 신뢰 구축** | 팀원들과의 신뢰 관계를 구축한 경험은? 어떤 어려움이 있었고 어떻게 극복했나요? |
| **사기 저하 해결** | 팀의 **사기나 생산성이 떨어졌던 문제**를 개선한 경험은? 원인과 해결책은? |
| **약속 불이행 경험** | 팀원과의 약속을 지키지 못한 경험은? 그 이유와 후속 조치는? |
| ♂ **협조 거부 상황** | 협업이 필요한 상황에서 **거부하거나 반대하던 동료**를 설득한 경험은? |
| **피드백 전달 및 수용** | 최근에 동료에게 피드백을 준 경험은? 상대방 반응은 어땠나요? 또는 피드백을 받은 경험은? |
| **어려운 진실 전달** | 말하기 껄끄러운 **사실이나 피드백을 전달한 경험**은? 어떤 방식으로 전달했나요? |
| **큰 변화 소통** | 구성원들이 우려할 만한 **방향 전환을 효과적으로 전달한 경험**은? 어떤 방식으로 질문과 저항에 대응했나요? |

### **몇 개의 사례를 준비해야 할까?**

보통 각 리더십 원칙당 **2개의 사례** 준비가 권장되지만,

**“Earn Trust”**는 다양한 맥락에서 자주 나올 수 있기 때문에 **3~4개의 유연한 사례**를 준비해 두는 것이 좋습니다.

### **TIP:**

- **“Ownership”, “Learn and Be Curious”, “Are Right, A Lot”** 등의 사례를 **신뢰 관점에서 재해석**해 활용 가능

### **좋은 답변의 핵심 요소**

| **요소** | **설명** |
| --- | --- |
| **자기 인식** | 본인의 부족함이나 실수에 대해 회피하지 않고 **직시하고 공유**함 |
| **책임 수용** | 문제가 발생했을 때 **남 탓이 아닌 자기 책임을 강조** |
| **신뢰 행동** | 피드백 수용, 경청, 예의, 약속 준수 등 **신뢰 행동을 일관되게 실천**한 사례 |
| **결과 향상** | 이런 태도가 팀/프로젝트에 **긍정적 변화로 연결**되었음을 설명 |

### **피해야 할 응답 유형**

- “난 완벽해서 신뢰를 잃은 적이 없다” → **자기 인식 부족, 비현실적**
- “팀이 나를 믿지 않아서 실패했다” → **책임 회피**
- “그 사람은 그냥 싫었고 말 안 들었다” → **비전문적 태도**

### **정리**

| **핵심 질문** | **확인 포인트** |
| --- | --- |
| 신뢰를 어떻게 얻었는가? | 커뮤니케이션, 존중, 일관된 행동 |
| 신뢰가 깨질 상황에서 어떻게 복구했는가? | 책임 수용, 회복 탄력성 |
| 피드백을 주고받는 문화에서 어떤 역할을 했는가? | 정직함, 성장 지향 태도 |
