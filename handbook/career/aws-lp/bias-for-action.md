> "빠른 결정을 내리고 실행에 옮깁니다."

## ** 아마존의 공식 정의:**

> **속도는 비즈니스에서 매우 중요하다.**
>
> 많은 결정과 행동은 **되돌릴 수 있는 경우가 많기 때문에**, 장시간의 분석이 필요하지 않다.
>
> 우리는 **계산된 리스크 감수**를 중요하게 여긴다.

## ** “Bias for Action”의 실제 의미는?**

**“Bias for Action”**은 **결정과 행동을 미루지 않는 태도**를 말합니다.

특히 불확실한 상황에서 주저하지 않고 **책임지고 결정하고 움직이는 사람**이 바로 Amazon이 선호하는 리더입니다.

> 분석만 하다가 아무것도 하지 못하는 상태(=분석 마비, *analysis paralysis*)는 Amazon에서 **용납되지 않습니다.**

## ** 아마존은 다음과 같은 행동 성향을 가진 인재를 원합니다:**

- **결정을 피하지 않고**, 직접 나서서 움직이는 사람
- 데이터는 참고하되, **데이터 수집에만 머물지 않고 실천에 옮기는 사람**
- 불확실성을 두려워하지 않고, **계산된 위험을 감수할 수 있는 사람**
- 자신뿐 아니라 팀원에게도 “일단 해보자”는 **실행 중심 문화를 장려**하는 사람

## ** “Bias for Action”을 가진 사람의 특징**

- 어려운 결정을 마주했을 때 **망설이지 않고 결정한다.**
- 팀원들에게도 **행동 우선의 문화**를 심어주며, 실패하더라도 **책임지고 지지한다.**
- 중요한 정보가 누락되어 있더라도, **정보를 빠르게 수집하거나 일단 전진한다.**
- “그건 내 일이 아니야”가 아니라 **장애물을 제거하고 팀을 전진시킨다.**
- **문제가 생기면 기다리지 않고**, 스스로 해결책을 시도한다.
- 막히면 **바로 도움을 요청**하며, **정체된 상황을 오래 방치하지 않는다.**

## ** “Bias for Action” 관련 자주 나오는 면접 질문**

| **질문 유형** | **질문 예시** |
| --- | --- |
| **리스크 감수** | 위험을 감수한 경험은? 어떤 위험이었고, 결과는 어땠나요? |
| **불완전한 정보 하의 결정** | 정보가 부족한 상황에서 어떻게 결정을 내렸나요? 결과는? |
| **속도가 중요한 상황** | 속도가 핵심인 상황에서 **계산된 리스크**를 감수한 경험은? 어떻게 조치했나요? |
| **즉각적 의사결정** | 매니저에게 보고 없이 **즉석에서 중요한 결정을 내린 경험**은? |
| **문제 인식과 주도적 행동** | 누군가 해주길 기다리지 않고 **직접 문제를 해결한 경험**은? |
| **시간 부족 상황** | 촉박한 마감 속에서 모든 옵션을 고려할 수 없었던 결정 경험은? |
| **비협조적인 상대와 정보 수집** | 응답하지 않는 사람에게서 정보를 얻기 위해 어떤 노력을 했나요? |
| **팀의 실행력 부족** | 팀이 **행동을 주저할 때** 어떻게 움직이게 만들었나요? (Manager) |
| **장애물 제거** | **팀의 진척을 막는 장애물**을 제거했던 경험은? 어떻게 해결했나요? (Manager) |

## ** 몇 개의 사례를 준비해야 할까?**

기본적으로 원칙당 **2개의 사례**가 권장되지만,

“Bias for Action”은 자주 나오는 원칙 중 하나이므로 **3~4개 이상**의 유연한 사례가 필요할 수 있습니다.

▶ **TIP**:

- **“Think Big”, “Deliver Results”, “Ownership”** 관련 사례를 **“Bias for Action” 관점**으로 재구성해 활용 가능
- 예: “불확실한 상황에서 팀을 이끈 경험”은 “Bias for Action” + “Leadership”을 모두 설명할 수 있음

## ** 좋은 답변의 핵심 구성 요소**

| **핵심 요소** | **설명** |
| --- | --- |
| **계산된 리스크 감수** | 무작정 행동한 것이 아니라, 빠르게 리스크를 분석하고 결정한 점 강조 |
| **속도 중심 의사결정** | 느린 접근보다 행동을 우선시한 이유 설명 |
| **직접 해결에 나섬** | “기다렸다”가 아닌 **직접 팔 걷어붙인 구체적 행동** 포함 |
| **결과 기반** | 실패했더라도 무엇을 배우고 다음에 어떻게 개선했는지 연결할 것 |

## ** 피해야 할 답변 유형**

- “모든 가능성을 다 검토해야 움직인다” → 과도한 분석은 Amazon에서 **비효율로 간주**됩니다.
- “실패가 두려워 보고만 있었다” → **책임 회피형** 리더로 오해받을 수 있음
- “기다리면 누군가 해결할 줄 알았다” → **자율성과 주도성 부족**으로 평가됨

## ** 정리**

| **질문 핵심** | **평가 포인트** |
| --- | --- |
| 빠르게 행동할 수 있었는가? | 속도 중심 의사결정 |
| 실패를 감수할 용기가 있었는가? | 리스크 인식과 책임감 |
| 실행을 통해 어떤 변화를 만들었는가? | 실질적 결과 도출 |
