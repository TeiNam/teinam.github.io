이 장은 **팀 컨벤션**이다. 표준 SQL 과 엔진 문서에는 약어 목록에 관한 규정이 없으므로, 아래 표는 팀 안에서 합의한 값이고 늘리거나 줄이는 결정도 팀이 한다.

> **IMPORTANT** — 원칙
>
> - 충분히 통용되고 의미 손실이 없는 단어만 약속하에 약어로 쓴다.
> - 약어 규칙은 **최소한**으로 유지한다.
> - 목록에 없는 약어는 쓰지 않는다. 필요하면 먼저 목록에 추가한다.

| 번호 | 대상 | 약어 |
| --- | --- | --- |
| 1 | number | `no` |
| 2 | address | `addr` |
| 3 | episode | `ep` |
| 4 | transaction | `tx` |
| 5 | count | `cnt` |
| 6 | authentication | `auth` |
| 7 | introduce | `intro` |

약어는 4-2 의 길이 초과 처리에서 첫 번째 수단으로 쓰인다.
