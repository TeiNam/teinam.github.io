> **검증 노트 (2026-09) · 참고** — 2021년 5.0 출시 시점의 기능 소개로는 정확한 기록입니다. 5.0 은 2024-10-31 EOL 이고 2026-09 현재 GA 는 8.3 이므로 "최신 버전" 맥락으로 읽으면 안 됩니다.

## MongoDB 5.0 New Features

최근 종료된 MongoDB.live 이벤트에서 범용 데이터베이스 플랫폼 MongoDB가 버전 5.0을 출시했습니다. MongoDB 5.0은 기본 시계열(native time series) 지원, MongoDB Atlas의 Serverless 데이터베이스, Atlas Search, Atlas Data Lake, 모바일 데이터 솔루션 Realm 개선을 포함합니다. 이 업데이트로 개발자는 데이터베이스 관리 작업 시간을 줄이고 생산성을 높일 수 있습니다. 하이브리드 소프트웨어 개발과 보안·개인정보 보호가 강화된 워크로드 관리가 더 빨라집니다.

MongoDB의 사장 겸 CEO인 Dev Ittycheria는 "오늘 발표는 개발자 경험에서 훨씬 더 많은 마찰과 복잡성을 제거하고 개발자가 다른 플랫폼보다 더 빠르게 광범위한 사용 사례를 위한 확장 가능한 애플리케이션을 구축할 수 있게 합니다."라고 말했습니다.

### Native time-series features

시계열 데이터는 관리하기 어렵습니다. 시간 흐름에 따라 처리되며 수집률이 높습니다. 결과적으로 개발자는 매우 많은 양의 데이터를 처리해야 합니다. 또한 이러한 데이터는 매우 작은 업데이트에도 순서가 뒤집힙니다. 따라서 데이터 쿼리는 시간 기반 필터를 많이 사용하는 경우가 많습니다.

MongoDB 5.0의 새로운 시계열 기능은 IoT(사물인터넷)와 재무 분석을 위해 설계되었습니다. **Clustered Indexing**과 **Window function**이 추가된 시계열 컬렉션으로 개발자는 시계열 애플리케이션을 빠르게 구축하고 실행할 수 있습니다. 높은 스토리지 효율성, 임시 데이터 실시간 분석, 짧은 대기 시간 쿼리를 위해 스키마를 자동으로 최적화합니다.

시계열 컬렉션은 동일한 워크로드의 일반 컬렉션 옆에 위치하여 모든 워크로드를 지원합니다. 자동화된 데이터 수명 주기 관리를 통해 실시간 분석, 시각화, 온라인 보관, 기록 데이터 결합이 가능합니다.

시계열 데이터 관리 플랫폼 사용은 여러 이점을 제공합니다. 먼저 인덱스 크기와 I/O 작업을 크게 줄여 성능을 향상시킵니다. 전체 스토리지 크기도 줄입니다. 또한 수집, 저장, 쿼리, 실시간 분석, 시각화에서 온라인 보관 또는 데이터 노후화에 따른 자동 만료까지 전체 시계열 데이터 수명 주기를 효율적으로 관리합니다. 단일 쿼리 API로 모든 클래스의 워크로드를 구동할 수 있습니다.

### 원활한 데이터 리밸런싱

데이터 샤딩(sharding)은 데이터를 여러 서버에 분산 저장하는 기법으로, 데이터베이스 관리에서 중요한 부분입니다. 샤딩을 사용하면 데이터베이스 클러스터가 더 큰 데이터 세트를 공유하고 추가 개발자 요청을 동시에 처리할 수 있습니다.

MongoDB 5.0은 데이터베이스 다운타임이나 데이터 세트 내 복잡한 마이그레이션 없이 워크로드와 데이터베이스가 계속 성장하고 발전함에 따라 컬렉션의 샤드 키를 필요에 따라 변경할 수 있도록 Live Re-Sharding을 지원합니다.

### 미래 경쟁력을 갖춘 어플리케이션 호환성 (Future proof: application compatibility)

여기서 말하는 미래 경쟁력은 버전화된 API로 제공됩니다. 애플리케이션 수명 주기가 데이터베이스 수명 주기와 분리되어 다른 데이터베이스보다 앞선 제품 보장 수준을 제공합니다. 개발자는 데이터베이스가 그 아래에서 업그레이드 및 개선되더라도 애플리케이션 코드가 수년간 변경되지 않고 중단 없이 계속 실행될 것이라는 확신을 가질 수 있습니다.

### 다중 클라우드 보안 도구(Multi cloud-security tools)

MongoDB 5.0 플랫폼은 다중 클라우드 클러스터에 엄격한 데이터 개인정보 보호 제어와 함께 클라이언트 측 필드 수준 암호화를 제공합니다. 상시 감사 및 인증서 교체가 지원됩니다. 사용자가 애플리케이션 중단 없이 엄격한 보안 태세를 유지할 수 있도록 지원하여 어디서나 애플리케이션을 실행할 수 있는 자유를 제공합니다.

고유한 클라이언트 측 필드 수준 암호화로 특정 데이터 필드에서 데이터를 암호화할 수 있습니다. 단일 키는 클라이언트가 메시지를 암호화하고 해독하는 데 사용됩니다.

### MongoDB Atlas Now의 서버리스 데이터베이스

MongoDB 5.0은 프리뷰에서 서버리스 인스턴스를 제공합니다. 사용자는 클라우드 리전을 선택하고 객체를 코드로 직접 매핑하는 문서로 구축을 시작할 수 있습니다. 하위 호환성 및 업그레이드에 대해 걱정할 필요가 없습니다.

### 다른 특징들

MongoDB 5.0의 기타 개선 사항은 다음과 같습니다.

- Atlas Search에는 문서 내 필드에 수학 공식을 적용하는 Function Scoring이 포함되어 있습니다. 사용자는 특정 검색 색인에 동의어를 정의할 수도 있습니다.
- Realm을 사용하여 실시간 점수 및 플레이어 통계와 같은 게임 데이터를 저장하고 장치 간 자동 동기화가 가능합니다.
- MongoDB Charts가 Atlas Data Lake와 통합되어 사용자는 데이터 이동, 복제 또는 변환 없이 Amazon AWS S3에 저장된 데이터를 시각화할 수 있습니다.
