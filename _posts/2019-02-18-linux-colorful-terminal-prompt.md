터미널 프롬프트에 색상을 적용하면 서버마다 다르게 설정하여 실수를 줄일 수 있습니다. Bash의 `PS1` 환경 변수에 ANSI 색 코드를 사용합니다.

> **NOTE** — 이 가이드는 Bash 기준입니다. macOS는 Catalina (2019) 이후 기본 셸이 zsh이므로, zsh를 사용하는 경우 `~/.zshrc` 에서 프롬프트 문법이 다릅니다 (`%n`, `%m`, `%~`, `%F{color}` 등).

## Bash 프롬프트 설정

`~/.bashrc` 파일에 다음 내용을 추가합니다.

```bash
# vi ~/.bashrc

export PS1="\[\e[36;1m\]\u@\[\e[32;1m\]\h:\[\e[31;1m\]\w]# \[\e[0m\]"
export TERM=linux
```

설정을 적용합니다.

```bash
# source ~/.bashrc
```

## PS1 이스케이프 시퀀스

- `\u` — 현재 사용자명
- `\h` — 호스트명 (첫 번째 `.` 까지)
- `\w` — 현재 작업 디렉터리 (`$HOME` 은 `~` 로 표시)
- `\$` — 권한 표시 (root는 `#`, 일반 사용자는 `$`)

## ANSI 색 코드

ANSI 이스케이프 시퀀스는 `\e[` 로 시작하고 `m` 으로 끝납니다. 색 코드는 다음과 같습니다.

- `30` — 검정, `31` — 빨강, `32` — 초록, `33` — 노랑
- `34` — 파랑, `35` — 마젠타, `36` — 사이안, `37` — 흰색
- `1` — 굵게 (밝은 색), `0` — 리셋

**중요**: ANSI 이스케이프 시퀀스는 `\[` 와 `\]` 로 감싸야 합니다. 감싸지 않으면 줄바꿈이나 히스토리 편집 시 커서 위치가 깨집니다.

## 서버별 색상 예시

각 서버마다 다른 색상을 사용하면 구분이 쉽습니다.

```bash
# 개발 서버 (파란색)
export PS1="\[\e[34;1m\]\u@\[\e[36;1m\]\h:\[\e[37m\]\w]# \[\e[0m\]"

# 운영 서버 (빨간색 - 주의)
export PS1="\[\e[31;1m\]\u@\[\e[33;1m\]\h:\[\e[37m\]\w]# \[\e[0m\]"
```
